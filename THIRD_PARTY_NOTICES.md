# 📦 Уведомления о сторонних компонентах (Third-Party Notices)

GoContact Studio использует сторонние открытые библиотеки. Они **не** лицензированы под AGPL v3 проектом — каждая сохраняет собственную лицензию. Коммерческая лицензия GoContact Studio на них **не распространяется**.

## 1. Прямые зависимости

| Модуль | Версия | Лицензия (SPDX) | Совместимость с AGPL-3.0 и коммерческой лицензией |
| :--- | :--- | :--- | :---: |
| `fyne.io/fyne/v2` | v2.8.2 | `BSD-3-Clause` | ✅ |
| `modernc.org/sqlite` | v1.61.0 | `BSD-3-Clause` | ✅ |

Косвенные зависимости перечислены в [`go.mod`](./go.mod), а полный перечень лицензий всех модулей зафиксирован в отчёте [`docs/legal/third_party_licenses.csv`](./docs/legal/third_party_licenses.csv). Полные тексты лицензий сторонних модулей и базовых шаблонов хранятся в каталоге [`licenses/`](./licenses/).

Автоматическая проверка чистоты лицензий выполняется командой:

```powershell
go install github.com/google/go-licenses@latest
go-licenses report ./... > docs/legal/third_party_licenses.csv
go-licenses check ./... --disallowed_types=forbidden,restricted,unknown
```

## 2. Политика допустимых лицензий для новых зависимостей

| Категория | Лицензии | Решение |
| :--- | :--- | :--- |
| Разрешительные | `MIT`, `BSD-2/3-Clause`, `Apache-2.0`, `ISC`, `Zlib`, `0BSD`, `Unlicense` | ✅ Разрешены |
| Слабый copyleft | `MPL-2.0` | ⚠️ Только без изменения файлов библиотеки |
| Сильный copyleft чужих авторов | `GPL-2.0-only`, `GPL-3.0`, `AGPL-3.0`, `LGPL` | ❌ Запрещены (ломают коммерческую лицензию) |
| Source-available / неизвестные | `SSPL`, `BSL`, `Commons Clause`, без лицензии | ❌ Запрещены |

Тексты лицензий сторонних модулей поставляются вместе с исходниками в кэше модулей Go и должны прикладываться к бинарным дистрибутивам (папка `licenses/` в архиве релиза).
