## 2. Архитектура графических компонентов Fyne v2

| Компонент GUI | Назначение и реализация в `internal/ui` |
| :--- | :--- |
| **Окна (`Window`)** | Главное окно `fyne.Window` (`1200x760`), вспомогательные диалоговые окна и аналитические панели. |
| **Кнопки (`Button`)** | Тулбар с иконками (`widget.NewButtonWithIcon`), кнопки действий в карточке контакта (Primary, Danger, LowImportance). |
| **Поля ввода (`Entry`, `Select`, `Check`)** | Поле живого поиска с `OnChanged`, поля формы (`FirstName`, `LastName`, `Phone`, `Email`, `Address`), выпадающий список групп (`widget.NewSelect`), чекбокс «В избранное» (`widget.NewCheck`). |
| **Таблицы / Списки (`List`, `Table`)** | Виртуализированный список `widget.NewList` (плавный скроллинг даже на 10 000+ записей) и таблица аудита `widget.NewTable`. |
| **Меню (`MainMenu`)** | Верхнее меню `fyne.NewMainMenu`: *Файл* (Импорт, Экспорт, Бэкап, Выход), *Контакты* (Создать, Избранные, Обновить), *Инструменты* (Импорт из REST API, Аудит базы, Смена темы), *Справка* (О программе). |
| **Диалоговые окна (`Dialog`)** | Модальные окна: `dialog.ShowForm` (создание/редактирование), `dialog.ShowConfirm` (подтверждение удаления), `dialog.ShowError` (валидация), `dialog.ShowInformation`, файловые селекторы. |
| **Обработка событий** | Реактивные колбэки `OnTapped`, `OnChanged` (живой поиск), `OnSelected` (выбор контакта или группы). |
| **Потокобезопасность UI** | Обновление виджетов из фоновых горутин исключительно через `fyne.Do()`, предотвращающее гонки потоков рендеринга. |

## 3. Конкурентная модель и многопоточная обработка

Для высокой отзывчивости десктопного интерфейса (60 FPS) все дисковые, вычислительные и сетевые операции вынесены в фоновые горутины с использованием **трех параллельных механизмов**:

### 3.1. Пул воркеров (`Worker Pool`) для пакетного импорта и валидации
При импорте больших массивов CSV/JSON или контактов из внешнего API:
1. Создаются буферизованные каналы: задач `jobs := make(chan domain.Contact, 100)` и результатов `results := make(chan ImportResult, 100)`.
2. Запускается пул из $N = 4$ горутин (`go worker(id, jobs, results, &wg)`).
3. Каждая горутина параллельно нормализует телефоны, валидирует поля и проверяет дубликаты.
4. Отдельная горутина-агрегатор ожидает завершения воркеров через `sync.WaitGroup` и закрывает канал `results`.
5. Канал прогресса передает процент выполнения в интерфейс для плавной анимации `widget.NewProgressBar()`.

### 3.2. Фоновый планировщик автобэкапов на `select` и `time.Ticker`
При старте приложения запускается фоновая горутина планировщика:
```go
func (s *BackupScheduler) Start(ctx context.Context) {
    ticker := time.NewTicker(s.interval)
    defer ticker.Stop()

    for {
        select {
        case <-ctx.Done():
            // Корректное завершение при закрытии окна (Graceful Shutdown)
            return
        case <-s.triggerNowChan:
            // Немедленный бэкап по требованию пользователя
            _ = s.performBackup()
        case <-ticker.C:
            // Автоматический бэкап по расписанию
            _ = s.performBackup()
        }
    }
}
```

### 3.3. Потокобезопасный In-Memory Кэш с `sync.RWMutex`
Для мгновенного поиска по ID и проверки уникальности номеров без задержек дискового ввода-вывода используется структура `ContactCache`, защищенная мьютексом `sync.RWMutex`:
* Читающие операции используют разделяемую блокировку `mu.RLock() / mu.RUnlock()`.
* Операции вставки, обновления и инвалидации используют эксклюзивную блокировку `mu.Lock() / mu.Unlock()`.

## 4. Сетевое взаимодействие и локальный REST API

В пакете `internal/infrastructure/network` реализовано два сетевых контура на базе стандартной библиотеки `net/http`:

1. **Импорт контактов из внешнего REST API (`https://randomuser.me/api/?results=10`):**
   * Панель инструментов позволяет выполнить асинхронный HTTP GET-запрос с таймаутами (`context.WithTimeout`), десериализовать JSON и сохранить новые контакты в базу.
   * При недоступности сетевого соединения предусмотрен автоматический **Graceful Fallback** на встроенный локальный генератор контактов.
2. **Встроенный локальный HTTP REST API сервер (`:8089`):**
   * Приложение предоставляет легковесный локальный эндпоинт `http://127.0.0.1:8089/api/v1/contacts` для интеграции с внешними утилитами, скриптами автоматизации и браузером.
