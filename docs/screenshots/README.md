## 📐 Регламент работы со скриншотами и референсами для ИИ-агентов
При разработке каждой новой версии (`v0.X.0`):
1. **Сохранение референсов дизайна:** При получении концепт-артов или дизайн-макетов от пользователя/дизайнера, агент **обязан** сохранять их в каталоге `docs/screenshots/<версия>/references/` с префиксом `ref_*.png`.
2. **Снятие эталонных скриншотов реализации:** По завершении разработки интерфейса версии агент запускает headless UI-тесты с флагом `CAPTURE_SCREENSHOTS=1` и сохраняет актуальные скриншоты работы приложения в `docs/screenshots/<версия>/` с префиксом `ui_*.png`.
3. **Регистрация в документации:** Агент регистрирует все референсы и скриншоты в настоящем реестре [`docs/screenshots/README.md`](./README.md) с кратким описанием каждого экрана.
4. **Сравнение референса и реализации:** В отчётах релиза сопоставлять реализованные элементы с референсами, фиксируя перенесённые в следующие фазы компоненты.
