# 🔐 Политика информационной безопасности (Security Policy)

## Поддерживаемые версии

| Версия | Статус поддержки безопасности | Примечания |
| :---: | :---: | :--- |
| `0.1.x` | ✅ Активно поддерживается | Базовый релиз локального хранения SQLite WAL |
| `0.8.x+` (План) | 🔜 В разработке | Внедрение Zero-Knowledge `AES-256-GCM` + `Argon2id` и хеш-цепочки аудита |

## Принципы безопасности GoContact Studio

1. **Local-First & Приватность по умолчанию:** база данных контактов хранится исключительно локально на устройстве пользователя (`data/addressbook.db`) и не отправляется на сторонние аналитические или облачные серверы.
2. **Изоляция сетевого API:** встроенный REST API сервер привязывается строго к локальному петлевому интерфейсу `127.0.0.1` (loopback) и недоступен из внешней локальной сети без явной настройки.
3. **Защита от SQL-инъекций:** все запросы к SQLite используют исключительно параметризованные выражения (`?` placeholders).
4. **Безопасность цепочки поставок (Supply Chain):** используется чистый Go-драйвер БД `modernc.org/sqlite` без загрузки непроверенных сторонних `.dll` / `.so` расширений.

## Сообщение об уязвимостях

Если вы обнаружили уязвимость безопасности в исходном коде или зависимостях проекта:
1. **Не публикуйте** эксплойт в публичных GitHub Issues до выпуска исправления.
2. Откройте приватное уведомление через вкладку **Security -> Report a vulnerability** в репозитории GitHub `https://github.com/trollyHUB/gocontact-studio/security` с описанием шагов воспроизведения.
3. Срок первичного ответа мейнтейнеров — до **48 часов**.
