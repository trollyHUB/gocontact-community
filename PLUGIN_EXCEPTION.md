## 1. Преамбула и назначение исключения

GoContact Studio лицензируется на условиях **GNU Affero General Public License версии 3** (`AGPL-3.0-only`). Основная цель AGPL v3 — гарантировать, что модификации самого ядра системы и её сервисов остаются открытыми для сообщества.

В то же время проект поощряет создание богатой независимой экосистемы расширений:
* **WebAssembly (Wasm) плагинов** (песочница `wazero` в релизе `v0.9.0`);
* **Инструментов и серверов Model Context Protocol (MCP)** (релиз `v0.8.0`);
* **Внешних скриптов интеграции, ботов и коннекторов** (REST API, WebSocket, Webhooks, CardDAV).

Чтобы разработчики плагинов и корпоративные интеграторы могли разрабатывать как открытые, так и закрытые (проприетарные) модули расширения без риска юридического «заражения» копилефтом AGPL v3, Правообладатель настоящим предоставляет официальное **Исключение для плагинов (Plugin Exception)**.

## 2. Формулировка дополнительного разрешения (AGPL v3 Section 7)

В дополнение к разрешениям, предоставляемым лицензией GNU Affero General Public License версии 3, Правообладатель предоставляет Вам безотзывное право объединять, распространять и исполнять независимые модули расширения («Плагины») совместно с GoContact Studio при соблюдении следующих условий:

1. **Использование только публичных интерфейсов (Public Interfaces Only):**
   Плагин взаимодействует с GoContact Studio **исключительно** через один или несколько следующих публично документированных каналов:
   * **WebAssembly Plugin ABI** (функции импорта и экспорта `wazero`, описанные в `docs/roadmap/v0.9.0-wasm-plugins-cli-palette/`);
   * **Model Context Protocol (MCP)** по протоколу JSON-RPC 2.0 (через `stdio`, loopback HTTP или SSE);
   * **Сетевые интерфейсы:** Local REST API v1 (`http://127.0.0.1:8089/api/v1/*`), WebSocket Hub, CardDAV (RFC 6352/6578) или входящие/исходящие Webhooks.

2. **Отсутствие заимствования исходного кода ядра:**
   Исходный код Плагина **не содержит** скопированных фрагментов исходного кода ядра GoContact Studio (пакетов `internal/...` или `cmd/...`), за исключением файлов публичных спецификаций интерфейсов, заголовочных определений типов данных (DTO/ABI) и официальных клиентских SDK.

3. **Свобода выбора лицензии Плагина:**
   При соблюдении условий пунктов 1 и 2 настоящий Плагин **НЕ считается производным произведением** (Derivative Work) от GoContact Studio в контексте условий AGPL v3. Вы вправе лицензировать, распространять и использовать такой Плагин **под любой лицензией по вашему выбору**, включая коммерческие закрытые лицензии (Proprietary), MIT, Apache 2.0, BSD или GPL.

4. **Сохранение силы AGPL v3 для ядра:**
   Настоящее Исключение не распространяется на сам исходный код GoContact Studio и любые его прямые модификации: ядро системы, встроенные модули и исправления остаются строго под условиями GNU AGPL v3 (или Коммерческой лицензии Правообладателя).

| Компания написала закрытый Wasm-плагин для обогащения контактов из внутренней ERP по ABI | ✅ **Разрешено под закрытой лицензией** |

| Разработчик изменил код пакета `internal/service/contact_service.go` ядра | ❌ **Действует AGPL v3** (требуется открыть изменения или приобрести коммерческую лицензию) |
